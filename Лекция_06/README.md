# Практикум 6 · MCP

Лекция 6. MCP. Задание — [слайд на сайте курса](https://edwfa.github.io/mas-lecture/lecture/06/slide-26.html).

Свой MCP-сервер p0042-fhir и проверка на стороне хоста.

## Что сделать

1. **Сервер.** ресурсы Condition и Observation, инструмент egfr, заготовка renal_check.
2. **Тесты.** СКФ для трёх эталонных случаев; ребёнок, перепутанные единицы и пол вне схемы — отказ с понятной причиной.
3. **Хост.** admit по слайду 23: изменённое описание lab_reference не доходит до модели.
4. **Запись.** chart_write возвращает input_required и пишет только после ответа врача.

## Файлы решения

- `server.py` — p0042-fhir на FastMCP
- `tools.md` — описания и схемы
- `admit.py` — отпечатки инструментов
- `tests/` — СКФ · ошибки · отравление
- `SECURITY.md` — права и контур
