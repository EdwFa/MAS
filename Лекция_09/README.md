# Практикум 9 · Оркестрация RAG

Лекция 9. Оркестрация RAG. Задание — [слайд на сайте курса](https://edwfa.github.io/mas-lecture/lecture/09/slide-24.html).

Оркестрация поверх модулей лекции 8 на том же наборе из 30 вопросов.

## Что сделать

1. **Маршрут.** route_question: таблица путаницы по трём видам; ни одного сложного вопроса по пути «факт из карты».
2. **Ветви.** search_all: при отключённом источнике ответ приходит с пометкой «не проверено».
3. **Цикл.** answer_loop: не больше трёх шагов; повтор запроса останавливает цикл; пустой контекст — «не найдено».
4. **Сравнение.** прямая цепь против потока: качество по видам вопросов, шаги и время на вопрос.

## Файлы решения

- `route.py` — маршрут по сложности
- `branches.py` — параллельные подзапросы
- `grade.py` — хватит ли найденного
- `loop.py` — цикл с бюджетом
- `eval/` — метрики по типам

## Что уже есть в каркасе P-0042
