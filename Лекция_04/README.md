# Практикум 4 · Инструменты, планирование, ансамбли

Лекция 4. Инструменты, планирование, ансамбли. Задание — [слайд на сайте курса](https://edwfa.github.io/mas-lecture/lecture/04/slide-26.html).

Агент с тремя инструментами и заглушкой МИС на учебном случае P-0042.

## Что сделать

1. **Описания.** Три инструмента по слайду 5; модель выбирает верный на 6 вопросах.
2. **Диспетчер.** dispatch по слайду 11: чужое имя, пустой аргумент, запись без подписи — отказы с причиной.
3. **Ошибки.** Заглушка МИС отдаёт пусто, ошибку и таймаут — в ответе нет выдуманных чисел.
4. **План.** run_plan по слайду 20: шаг вне списка отвергнут; событие лаборатории — перепланирование.

## Файлы решения

- `tools.py` — 3 схемы инструментов
- `dispatch.py` — проверки перед вызовом
- `mis_stub.py` — заглушка МИС
- `plan.py` — план из списка шагов
- `tests/` — 8 случаев

## Что уже есть в каркасе P-0042

- [`p0042/tools.py`](../P-0042/p0042/tools.py) — инструменты, диспетчер: имя → схема → лимит → политика
- [`p0042/fhir.py`](../P-0042/p0042/fhir.py) — заглушка МИС: учебная карта FHIR
