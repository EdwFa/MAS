# Практикум 5 · Агенты с памятью

Лекция 5. Агенты с памятью. Задание — [слайд на сайте курса](https://edwfa.github.io/mas-lecture/lecture/05/slide-25.html).

Память для мини-агента пакета P-0042: три дня работы, два пациента, один врач.

## Что сделать

1. **Запись.** remember по слайду 18: пересказ вместо ссылки отвергнут; у записи есть автор и дата.
2. **Чтение.** recall: поиск по P-0042 не находит ничего из P-0051.
3. **Три дня.** агент продолжает работу в «среду» по состоянию «понедельника» и перечитывает записи по ссылкам.
4. **Ревью.** propose_instruction: правка лежит в proposals, агент работает по active.

## Файлы решения

- `memory.py` — remember · recall
- `namespaces.md` — случай · врач · ревью
- `proposals.py` — правка на ревью
- `tests/` — 6 случаев
- `retention.md` — сроки и удаление
