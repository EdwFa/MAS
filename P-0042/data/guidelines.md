3 Лечение

3.1 Общие принципы

3.1.1 Рекомендуется обсуждать план лечения на мультидисциплинарном консилиуме до начала терапии.
(УУР A, УДД 2)
Комментарий: в пакет к консилиуму включают гистологию, ИГХ и функцию почек.

3.1.2 Рекомендуется перед системной терапией оценить функцию почек по расчётной СКФ (CKD-EPI 2021).
(УУР B, УДД 2)

3.2 Терапия при HER2-положительной опухоли

3.2.1 Рекомендуется рассматривать анти-HER2 терапию у пациентов с HER2 3+ по ИГХ.
(УУР A, УДД 1)
Комментарий: при HER2 2+ требуется подтверждение ISH.

3.2.2 Рекомендуется контроль функции сердца до и во время анти-HER2 терапии.
(УУР B, УДД 3)

3.3 Сниженная функция почек

3.3.1 Рекомендуется при СКФ ниже 60 мл/мин/1,73 м² проверять необходимость коррекции доз нефротоксичных и выводимых почками препаратов.
(УУР B, УДД 2)
Комментарий: решение о дозе принимает врач с учётом инструкции препарата.

3.3.2 Не рекомендуется использовать креатинин без расчёта СКФ для решения о дозе.
(УУР C, УДД 4)
