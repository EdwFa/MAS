## Кратко о случае

Женщина 67 лет. Рак левой молочной железы, инвазивная карцинома неспецифического типа, G2. ER 90%, PR 20%, HER2 3+, Ki-67 30% — люминальный B HER2-положительный подтип. Метастаз в левом аксиллярном лимфоузле. По КТ и сцинтиграфии отдалённых метастазов нет; предварительная стадия cT2N1M0, IIB.

Сопутствующие болезни:
- сахарный диабет 2 типа, HbA1c 7,4%;
- артериальная гипертензия.

Принимает метформин, лизиноприл и аторвастатин. Аллергия на йодсодержащий контраст, поэтому КТ выполнена без контрастирования.

Креатинин 118 → 124 мкмоль/л, расчётная СКФ около 41 мл/мин/1,73 м² (G3b). ФВ ЛЖ 58%, кардиолог противопоказаний к анти-HER2 терапии не видит. Рост 162 см, масса 74 кг, ECOG 1.

Консилиум запланирован на пятницу 20.11. Агент собирает пакет с понедельника 16.11.
