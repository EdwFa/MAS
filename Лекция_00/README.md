# Практикум 0 · Окружение и случай

Лекция 1. Вводная. Задание — [слайд на сайте курса](https://edwfa.github.io/mas-lecture/lecture/01/slide-31.html).

Практикум 0: окружение и случай. Каждое следующее занятие опирается на него.

## Что сделать

1. **Окружение.** Python 3.10+, локальная модель в Ollama или LM Studio, каркас P-0042 из EdwFa/MAS. python check_env.py — все строки с ✓.
2. **Случай.** Прочитать data/README.md: пациентка, неделя до консилиума, ловушки в данных. Открыть пять документов карты глазами.
3. **Назначение.** Одна фраза в README: что система готовит, чего не делает и где останавливается — ход у врача.
4. **Граф.** Первый граф агентов пакета P-0042: кто читает, кто пишет, где пауза врача. К защите он изменится — это нормально.

## Файлы решения

- `check_env.py` — все строки ✓
- `data/README.md` — случай и ловушки
- `README.md` — назначение и предел
- `graph.png` — первый граф агентов
- `models.txt` — модель и скорость
