# Сверка стадии рака головы и шеи

## Шаги
1. Собери из пакета случая входные данные и сохрани в work/staging.json:
   site, p16 (для ротоглотки), basis (clinical или pathological), T, N, M,
   documented_stage, edition, и у каждого значения — ссылку на источник.
   Категории T, N, M бери только из заключений лучевой диагностики и
   патоморфологии. Сам по снимкам или тексту их не определяй.
2. Запусти: run_script со script = scripts/stage.py и file = work/staging.json.
3. Код 0 — стадия совпадает: сообщи врачу стадию, таблицу и издание.
4. Код 1 — расхождение: покажи врачу записанную и рассчитанную стадию,
   таблицу и издание. Вынеси расхождение в open_questions.
   Стадию в карте не исправляй.
5. Код 2 — посчитать нельзя: перечисли врачу, чего не хватает (поле из error).
   Не подставляй значения сам.
6. Если в ответе есть notes — перескажи их врачу дословно по смыслу:
   например, «p16 неизвестен — посчитано по таблице для p16-отрицательных».

## Нельзя
- Определять T, N, M самостоятельно: это заключение врача-рентгенолога и патоморфолога.
- Записывать стадию в карту: это chart_write, политика «спросить».
- Советовать лечение по стадии: это решение консилиума.

Скрипт исполняй, не читай. Таблицы стадий с источниками — references/staging_tables.md.
