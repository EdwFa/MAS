# Поля пакета к консилиуму (учебные)

| Поле | Что это | Пример |
| --- | --- | --- |
| case_id | номер случая | P-0042 |
| diagnosis_ref | ссылка FHIR на диагноз | Condition/c-17 |
| imaging_ref | ссылка на протокол визуализации | DocumentReference/ct-219 |
| histology_ref | ссылка на гистологию и ИГХ | DocumentReference/path-201 |
| board_date | дата консилиума ДД.ММ, «не назначена» или список спорных дат | 20.11 |
| open_questions | список открытых вопросов; пустой список допустим | [] |

Ссылка FHIR — строка вида `Тип/id`. Строка `ct-117` без типа — не ссылка.
