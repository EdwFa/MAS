# Практикум 17 · Опасности и безопасность системы

Лекция 17. Опасности и безопасность системы. Задание — [слайд на сайте курса](https://edwfa.github.io/mas-lecture/lecture/17/slide-30.html).

Документ безопасности для своей системы — на мини-harness лекций 13–16.

## Что сделать

1. **Опасности.** Перечень по образцу слайда 4, с оценкой по слайду 5.
2. **Правило двух.** Таблица «агент × три свойства» и чем закрыто каждое третье «да».
3. **Атаки.** 20 инъекций в пять входов; доля успешных; трасса одной отбитой атаки.
4. **Траектория и матрица.** check_trajectory на 10 случаях; матрица прослеживаемости на 5 строк.

## Файлы решения

- `hazards.md` — 9 опасностей
- `rule_of_two.csv` — агент × свойства
- `attacks/` — 20 инъекций
- `trajectory.py` — правила пути
- `trace_matrix.csv` — 5 строк

## Стартовый код — папка [`starter/`](starter/)

Готово и проверено тестами (`pytest -q Лекция_17/starter`, без модели и без сети):

| Файл | Что внутри |
| --- | --- |
| `hazards.md`, `risk.py` | перечень по слайдам 4–5: три строки-образца (Н1–Н3); сетка тяжесть × вероятность кодом; ревью: мера без теста не принимается |
| `rule_of_two.csv`, `rule_of_two.py` | агенты P-0042 по слайду 8; проверка: третье «да» без названного надзора — замечание |
| `trajectory.py`, `fixtures/trace_*.jsonl` | `check_trajectory` по слайду 19 и три трассы: правильная, запись до подписи, потерянный спор и сообщение от модели |
| `stub_world.py` | пять входов чужого текста (слайд 13) и граф с мерами: таблица прав, план кафедры, схемы артефактов, закреплённая карточка, пауза перед записью; `ObedientModel` выполняет любую инструкцию — худший случай |
| `attacks/attacks.jsonl` | 5 атак, по одной на вход, с определением успеха |
| `trace_matrix.csv`, `matrix.py` | три строки по слайду 25; проверка: ссылка на тест должна вести на существующую функцию |
| `tests/test_starter.py` | 24 теста: сетка риска, правило двух, тесты мер (уровень 1), траектория (уровень 3), набор атак (уровень 4), матрица и контрольный тест «без мер атаки проходят» |

Что остаётся вам:

1. Дописать в `hazards.md` опасности Н4–Н9 со слайда 4 и оценку; `risk.review` должен вернуть пустой список.
2. Довести `attacks/attacks.jsonl` до 20 атак (по 4 на вход), в том числе тонкие, без слов «система» и «запиши».
3. Подставить в `run_case(model=...)` настоящую локальную модель с методом `propose()` и посчитать долю успешных атак (слайд 21).
4. Прогнать `check_trajectory` на 10 трассах своего мини-harness и сдать `trace_matrix.csv` на 5 строк — каждая со ссылкой на тест.
