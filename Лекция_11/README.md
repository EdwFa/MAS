# Практикум 11 · Эмбеддинг чанка

Лекция 11. Эмбеддинг чанка. Задание — [слайд на сайте курса](https://edwfa.github.io/mas-lecture/lecture/11/slide-24.html).

Индекс протоколов по болезни Фабри и проверка поиска.

## Что сделать

1. **Чанки.** Структурная нарезка учебных PDF. Тест падает, если чанк длиннее 512 токенов.
2. **Индекс.** Коллекция с dense-вектором e5, payload по слайду 17, ID через uuid5.
3. **Вопросы.** 40 вопросов врача с номерами нужных чанков.
4. **Сравнение.** recall@10 для двух вариантов нарезки. Победитель идёт в конвейер лекции 10.

## Файлы решения

- `chunks.jsonl` — чанки и метаданные
- `index.py` — encode + upsert
- `questions.csv` — 40 вопросов и gold
- `eval.py` — recall@10
- `report.md` — два варианта чанкинга

## Данные

Учебные PDF протоколов по болезни Фабри выдаёт преподаватель. Каркас P-0042 здесь не нужен.

## Что сдают

Сдают код, таблицу recall@10 и два примера вопросов, где варианты нарезки разошлись.
