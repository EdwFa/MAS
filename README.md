# Практикум курса «Программная инженерия мультиагентных систем в клинической медицине»

Осень 2026 · © E.Fartushny · MIT. Сайт курса: [edwfa.github.io/mas-lecture](https://edwfa.github.io/mas-lecture/), все занятия — на [странице практикума](https://edwfa.github.io/mas-lecture/lecture/practicum/index.html).

Почти все практикумы строятся на одном учебном случае: агент готовит пакет к онкологическому консилиуму по вымышленной пациентке P-0042. Общий код и данные — в каркасе [`P-0042/`](P-0042/). В папке каждой лекции — задание: что сделать, что уже есть в каркасе, как проверить и что сдать.

## С чего начать

```bash
git clone https://github.com/EdwFa/MAS && cd MAS/P-0042
python -m venv .venv && source .venv/bin/activate      # Windows: Anaconda Prompt, .venv\Scripts\activate
pip install -r requirements.txt
python check_env.py                                    # практикум 0
```

Модель только локальная (Ollama, LM Studio, vLLM): данные пациента не покидают контур. Тесты идут без модели.

## Как сдавать

Один репозиторий на команду — копия этого. Каждое задание — отдельная ветка и pull request с тестами. К защите в репозитории собрана работающая система, а не набор упражнений.

Все данные вымышленные. Это учебный материал, а не клинический пример для решений о лечении.
