# Практикум 18 · От пилота к эксплуатации

Лекция 18. От пилота к эксплуатации. Задание — [слайд на сайте курса](https://edwfa.github.io/mas-lecture/lecture/18/slide-24.html).

Готовим каркас P-0042 к пилоту: релиз, проверка, тихий режим, метрики, RUNBOOK, интерфейс врача.

## Что сделать

1. **Релиз.** release.yaml с версиями модели, промптов, индекса, сервера и порогов; номер релиза в каждой трассе.
2. **Проверка.** gate по слайду 13 на наборе вопросов и атак; один релиз, который проверку не проходит, и почему.
3. **Тихий режим.** silent_compare на 10 размеченных пакетах; разбор каждого doctor_only.
4. **Эксплуатация.** daily по трассам; RUNBOOK: отказы, откат, роли, ручной режим.
5. **Интерфейс врача.** ui/app.py: пакет агента рядом с базовым пакетом без модели; запись в карту только после просмотра открытых вопросов.

## Что уже есть в каркасе P-0042

- [`release.yaml`](../P-0042/release.yaml) — релиз как набор версий
- [`p0042/ops.py`](../P-0042/p0042/ops.py) — gate, silent_compare, daily

Решение пишут в своей копии репозитория, в отдельной ветке; код каркаса можно менять и расширять.
