# Практикум 7 · Извлечение знаний. RAG

Лекция 7. Извлечение знаний. RAG. Задание — [слайд на сайте курса](https://edwfa.github.io/mas-lecture/lecture/07/slide-30.html).

Минимальный RAG по учебному протоколу. Дальше — лекция 8: две трудности наивного контура и модульный RAG.

## Что сделать

1. **База.** 30 фрагментов учебного протокола с id, источником и версией; одна устаревшая редакция.
2. **Поиск.** build_index и search по слайду 20; recall@4 на 20 вопросах с известным фрагментом.
3. **Ответ.** Промпт по слайду 19; check_citations по слайду 21 на всех ответах.
4. **Отказ.** 5 вопросов вне базы: доля честных «нет в базе».

## Файлы решения

- `protocol/` — 30 фрагментов
- `index.py` — эмбеддинг и поиск
- `questions.csv` — 20 вопросов + нужный id
- `rag.py` — промпт и ответ
- `check.py` — ссылки и recall@k

## Что уже есть в каркасе P-0042
