# Практикум 3 · Цепочки, маршрутизация, параллельность

Лекция 3. Цепочки, маршрутизация, параллельность. Задание — [слайд на сайте курса](https://edwfa.github.io/mas-lecture/lecture/03/slide-25.html).

Четыре паттерна на учебной карте P-0042. Модель можно заменить заглушкой: проверяем устройство, а не качество текста.

## Что сделать

1. **Цепочка.** chain по слайду 7: ответ не по схеме останавливает цепочку с причиной.
2. **Маршрут.** route по слайду 12: случай с красным флагом и случай с p = 0,6 уходят к врачу.
3. **Параллельность.** read_all по слайду 15: один читатель зависает — сводка приходит за 60 с с причиной.
4. **Рефлексия.** refine по слайду 18: критик всегда недоволен — цикл останавливается после двух кругов.

## Файлы решения

- `chain.py` — цепочка с проверкой
- `router.py` — правило + порог
- `readers.py` — asyncio + таймаут
- `refine.py` — критик ≤ 2 кругов
- `tests/` — 6 случаев
