# Практикум 8 · RAG из модулей

Лекция 8. RAG из модулей. Задание — [слайд на сайте курса](https://edwfa.github.io/mas-lecture/lecture/08/slide-23.html).

Модульный RAG по учебному набору рекомендаций для вопроса консилиума P-0042.

## Что сделать

1. **Индекс.** chunk_guideline: все пары «рекомендация — УДД» целы; метаданные с версией.
2. **Поиск.** hybrid_search с RRF; отменённая редакция не попадает в выдачу.
3. **Отбор.** select с порогом и бюджетом; пустой контекст — честный отказ.
4. **Измерение.** метрика каждого модуля на 30 вопросах; таблица «до и после» для одного добавленного модуля.

## Файлы решения

- `chunk.py` — нарезка по разделам
- `plan.py` — подзапросы по схеме
- `search.py` — BM25 + векторы + RRF
- `select.py` — отбор по бюджету
- `eval/` — метрики модулей

## Что уже есть в каркасе P-0042

- [`p0042/rag.py`](../P-0042/p0042/rag.py) — chunk_guideline, hybrid_search, rrf, select
