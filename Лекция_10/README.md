# Практикум 10 · Архитектура быстрых решений

Лекция 10. Архитектура быстрых решений. Задание — [слайд на сайте курса](https://edwfa.github.io/mas-lecture/lecture/10/slide-31.html).

Фильтр для конвейера болезни Фабри. Учебные PDF протоколов.

## Что сделать

1. **Разметка.** 300 пар «вопрос врача — фрагмент» с меткой 0 или 1. Две трети на калибровку, треть на проверку.
2. **Фильтр.** bge-reranker-v2-m3 и Platt, код со слайда 17.
3. **Отчёт.** Brier, ECE и полнота при пороге из threshold_for_recall с target = 0,95.
4. **Хук.** Подключить фильтр к мини-harness из лекции 13: решение и p — в трассу.

## Файлы решения

- `labels.csv` — 300 пар
- `filter.py` — реранкер + Platt
- `platt.json` — a и b
- `report.md` — Brier, ECE, recall
- `trace.jsonl` — решения и p

## Данные

Учебные PDF протоколов по болезни Фабри выдаёт преподаватель. Каркас P-0042 здесь не нужен.

## Что сдают

Сдают код, таблицу с тремя числами и трассу одного запроса, где фильтр что-то отбросил.
