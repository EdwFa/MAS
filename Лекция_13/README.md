# Практикум 13 · Harness агента

Лекция 13. Harness агента. Задание — [слайд на сайте курса](https://edwfa.github.io/mas-lecture/lecture/13/slide-39.html).

Около 150 строк Python. Модель — любая доступная. Данные — учебный случай P-0042.

## Что сделать

1. **Цикл.** С лимитом шагов и записью причины остановки.
2. **Реестр.** Три инструмента: fhir_read, draft_write, chart_write. Схемы с additionalProperties: false.
3. **Права.** Таблица allow / ask / deny из файла. Ask останавливает цикл.
4. **Хук.** Маскирование ПДн после каждого чтения.
5. **Трасса.** JSONL, одна строка на оборот.
6. **Тест.** Падает, если chart_write исполнен без подписи.

## Файлы решения

- `harness.py` — цикл
- `tools.py` — реестр
- `policy.yaml` — права
- `hooks.py` — хук
- `trace.jsonl` — трасса
- `test_harness.py` — тест
