# Защита проекта

Девятнадцатая встреча. Слайды — [на сайте курса](https://edwfa.github.io/mas-lecture/lecture/19/slide-01.html); чек-лист — ниже.

Сдают один репозиторий на команду — копию этого, с решениями практикумов 0–18 — за три дня до защиты. Тесты преподаватель запускает сам, до доклада.

Обязательно в репозитории:

- `README.md`: назначение и предел системы;
- граф и права: `graph.py`, `policy.csv`, `rule_of_two.csv`;
- скиллы, контракты передачи, трасса случая P-0042 с подписью врача;
- тесты пяти уровней и `trace_matrix.csv`;
- `eval_result.json` со сравнением с базовым пакетом без модели;
- `release.yaml`, `RUNBOOK.md`, экран врача `ui/`.
